Standardize text

Powers the wand button beside a task's name and description. Keys are stored in this browser only and are deliberately left out of the backup file. Two engines, both free to run: Google AI Studio issues a key with no card and a free tier, which is the default, and OpenRouter's ":free" models cost nothing per token. All engines lists both at once, and picking a model fills the Engine box with the engine that owns it.

For Gemini this is the app's own labelling by model name, because Google's model list carries no billing information; OpenRouter publishes its prices, so its split is read from the account. Every "pro" model counts as paid. Nothing is hidden for good — Show everything lists all of them. The one exception is Google's 2.5 flash family, which is withdrawn rather than hidden: it now answers "no longer available to new users".
Saved per engine, and grouped by what each model is for. The list is read from your own account once a key is in place.
